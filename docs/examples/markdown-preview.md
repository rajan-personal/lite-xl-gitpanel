# Markdown, without leaving Lite XL

A **read-only preview** alongside your normal editor.
Render *local documents* without a hosted service.

## Everyday formatting

- Keep your source tab and unsaved edits.
- Use **Refresh** to read the latest buffer.
- Choose **Source** to return to editing.

1. Open a Markdown file.
2. Press `Ctrl+Shift+M`.
3. Read, navigate, and return to your source.

> Previewing never saves, stages, or modifies a file.
